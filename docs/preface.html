Technical Overview of Leo¶

Leo completely integrates Python scripting and outlines, creating a fundamentally different way of using and organizing data, and computer programs. Leo has been under active development for 45+ years with an active group of developers and users.

  • Scripts have complete access to outline structure via a simple Python API. Examples:
    c.p.b is the body text of the selected outline node.
    for p in c.all_nodes() iterates p through all the nodes of the outline.

  • Unlike standard tree-based editors, Leo allows a cloned node to appear in multiple places simultaneously. Editing a node in one location updates it everywhere. Clones allow you to create multidimensional views of any data, including source code.

  • Leo’s clone find commands create organized clones of all the nodes that match the search criteria. These data create a new way to refactor computer programs.

  • Scripts and programs can be composed from outlines using outline-oriented directives.

  • Importers convert flat text files into outlines.

  • @button scripts apply scripts to outline data.

These features combine to create a new (Leonine) way of organizing complex data, including computer programs.
